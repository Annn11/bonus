# Судоку 9×9 через WebDataRocks

Бонусне завдання виконано у 3 основних файлах:
- `index.html`
- `style.css`
- `script.js`

## Як запустити
1. Відкрийте папку у VS Code.
2. Запустіть `index.html` через Live Server.
3. Інтернет має бути увімкнений, бо WebDataRocks підключено через CDN.

## Як грати
1. Основне поле гри показане через таблицю WebDataRocks.
2. Якщо кліки по таблиці не працюють у браузері, використовуйте механічний вибір:
   - виберіть рядок 1–9;
   - виберіть стовпець A–I;
   - натисніть «Обрати клітинку»;
   - натисніть число 1–9.
3. Сині клітинки — початкові, їх змінювати не можна.
4. Кнопка «Перевірити» підсвічує помилки.
5. Кнопка «Підказка» заповнює одну правильну клітинку.
6. Кнопка «Нова гра» створює нове поле.
